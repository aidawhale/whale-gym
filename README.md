This is a small WIP proyect to learn some SwiftUI and iOS basics, following the [iOS getting strted tutorials](https://developer.apple.com/tutorials/develop-in-swift/).

The developed app is aimed to support gym training sessions and keep track of the exercicies and weights/reps.
